Subject Details

1. Entrepreneurship

Entrepreneurship teaches students how to start and manage a business.

2. Mathematics

Mathematics helps students develop logical thinking and problem-solving skills.

3. Architectural Organization Of Computers

This subject provides knowledge about computer hardware, memory, CPU, and computer organization.

4. Environmental Science

Environmental Science teaches students about the environment, pollution, and conservation of natural resources.

5. Programming Practices (Basics Of C)

Students learn to write and execute programs using C programming language.

6. Basics Of Web Development

Students learn to create webpages using HTML tags and basic web development concepts.
